# Pet Adoption Network

Plataforma para divulgação de pets disponíveis para adoção e pets perdidos.

## Como rodar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse o endereço que aparecer no terminal.

## Observação

- `node_modules/` e `dist/` não devem ser enviados ao GitHub.
- `README.md` pode ficar no repositório, pois só explica o projeto.
